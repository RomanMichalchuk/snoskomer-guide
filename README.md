# Сноскомер: Протокол и метрики аналитики цитирования в генеративном поиске

Открытая спецификация методологии Сноскомер для измерения доли голоса (Share of Voice), частоты перехода по сноскам и качества присутствия брендов в ответах нейросетей (ChatGPT, Яндекс Нейро, Perplexity, Gemini).

Разработано исследовательской лабораторией аналитического сервиса [Сноскомер](https://snoskomer.ru/).

## Основные метрики анализа генеративного поиска

1. **Share of Citations (SoC)**: отношение количества сносок на целевой ресурс к общему объему сносок в нейроответах по кластеру запросов.
2. **First Citation Rate (FCR)**: вероятность появления источника в первой позиции среди источников ответа.
3. **Sentiment & Entity Context**: анализ контекста упоминания бренда (нейтральный, позитивный, экспертный).
